# StyleShift

音乐风格转换工具。上传一首歌，选一个目标风格，得到转换后的版本。

不是简单的 EQ 调色，是**按目标风格的规则重新生成伴奏**：鼓点重写、和声重构、音色替换、段落处理。

底层来自对「司凤音乐」这一网络流派的技术拆解——先搞清这种风格在数据上长什么样，再把它变成可执行的参数。

## 快速开始

### 1. 前端（无需后端也能跑）

```bash
# 直接用浏览器打开，或者起个静态服务
cd frontend
python -m http.server 8080 --bind 127.0.0.1
# 访问 http://127.0.0.1:8080
```

后端未启动时，前端自动降级到 **Web Audio 本地处理**，演示流程完整可走。

### 2. 后端（真实处理）

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8000
```

前后端一起跑时，前端会自动检测 `/api/convert` 并优先走真实处理。

## 三种目标风格

| 风格 | 音色 | 鼓 | 特殊处理 |
|---|---|---|---|
| **古典** | 弦乐四重奏 | 定音鼓，只打强拍 | 降速 60%，大混响 |
| **通透** | 低频轰炸 | 48Hz 正弦，每拍均等 | 高频砍 18dB，段落处插怪叫 |
| **8-bit** | 街机音源 | 噪声脉冲 + 方波 | 位深压到 4bit，降采样 4 倍 |

参数不是拍脑袋定的，全部来自实测数据（见 `docs/design.md`）。

## 技术架构

```
上传音频
   ↓
① 变速        librosa.time_stretch
   ↓
② 均衡        scipy 双段搁架滤波
   ↓
③ 鼓点检测    onset strength + peak picking
   ↓
④ 鼓点重写    按风格合成新鼓（正弦/噪声/方波）
   ↓
⑤ 位深压缩    仅 8-bit
   ↓
⑥ 插入怪叫    按用户标注的段落位置
   ↓
⑦ 混响        多抽头延迟
   ↓
输出 wav
```

**每个环节都是真实信号处理**，不是预设样本。

## 接口

```bash
# 转换
curl -X POST http://127.0.0.1:8000/api/convert \
  -F "audio=@song.mp3" \
  -F "style=tongtou" \
  -F 'marks=[{"time":30,"label":"怪叫"}]'
# → {"task_id": "abc123"}

# 查进度
curl http://127.0.0.1:8000/api/task/abc123
# → {"status":"done","progress":100,"output":"/api/audio/abc123"}

# 下载
curl -O http://127.0.0.1:8000/api/audio/abc123
```

## 给这个项目做过的分析

对六首同流派作品做了完整测量（`docs/analysis.md`）：

- **低频占比 42-53%**（正常流行歌 20-30%）
- **高频占比 2-4%**（正常 8-15%）
- **和声同质度 0.985-0.995**（全曲几乎不变）
- **鼓点拍级自相关 0.68-0.84**（规律极强，但无重音对比）

「拆迁感」的成因不是随机撒鼓，而是**密度过高 + 低频压倒 + 没有重音层次**。
