# Music Without Mother

对 2026 年 10 月 B 站流行的「司凤音乐」现象的技术拆解。

不包含任何音频文件。这里只有分析方法、数据和工具。

## 观察对象

「司凤音乐」是 2026 年 9-10 月兴起的网络音乐流派，核心是用 AI 歌手（代表音色「隆德齐」）翻唱各类歌曲，演唱腔调刻意抽象。

代表作品：

| 曲目 | 原曲 | UP 主 | 时长 |
|---|---|---|---|
| 《雨爱 (司凤版)》 | 杨丞琳《雨爱》 | 随安SuiAan | 140s |
| 《朋友的酒》司凤版 | 李晓杰《朋友的酒》 | 181319 | 237s |
| 《宇宙冷漠》司凤版 | 《宇宙冷漠》(BV19X9eBpEfS) | 账号已注销 | 222s |

其中《宇宙冷漠》原作本身也是 AI 生成：曲、唱、视频素材全由 AI 完成，只有词是人写的（@菜农来辣）。

## 流派特征（据公开评论归纳）

- 鼓点密集、切分混乱，被形容为「像拆迁」
- 电音音色失真，被形容为「像漏电」
- 人声刻意拧巴、频繁跑调
- 段落间插入无意义怪叫（「呼——哈——崩巴崩巴」）
- 刻意保留 AI 合成的机械感，不修音

核心是**刻意的粗糙**：把 AI 生成的缺陷当成风格标记。

## 技术方法

### 1. 音频获取

从 B 站客户端缓存提取。m4s 文件头前 9 字节是 ASCII 的 `000000000`，需跳过：

```bash
tail -c +10 input.m4s > output.m4a
ffmpeg -i output.m4a -vn -c:a libmp3lame -q:a 2 out.mp3
```

脚本见 `tools/bili_cache_extract.py`。

### 2. 音源分离

使用 demucs htdemucs 模型分离四轨：

```bash
python -m demucs -n htdemucs --out sep input.mp3
```

### 3. 数据分析

```bash
python tools/analyze.py input.mp3
```

输出 BPM、调性、逐轨响度、频谱特征。
