# 样本分析

三个样本均来自 B 站缓存，经 demucs 四轨分离后测量。

## 一、原始响度与分离结果

《雨爱 (司凤版)》各轨平均响度：

| 轨 | 平均响度 | 说明 |
|---|---|---|
| drums | -15.5 dB | 最响，主导 |
| vocals | -16.8 dB | 次之 |
| bass | -21.0 dB | 常规 |
| other | -27.9 dB | **极低** |

**关键观察**：`other` 轨（合成器、音效、弦乐等）比其他轨低 12 dB 以上，说明编配极其简单——主体只有鼓和人声，没有和声垫、没有弦乐铺底。

这是「通透」感的来源：信息量少，听不出层次，所以显得空。

## 二、与传统流行的对比

普通流行歌的四轨响度大致均衡（-18 到 -22 dB 之间），`other` 轨通常包含吉他、键盘、弦乐、pad，能量不低。

这首的 `other` 只有 -27.9 dB，意味着：

- 没有和声进行支撑
- 没有编曲层次
- 全靠鼓的节奏和人声的旋律撑住

## 三、分离流程

```bash
# 1. 从 B 站缓存提取音频
tail -c +10 <cid>-1-30280.m4s > tmp.m4a
ffmpeg -i tmp.m4a -vn -c:a libmp3lame -q:a 2 song.mp3

# 2. 四轨分离
python -m demucs -n htdemucs --out sep song.mp3
```

输出：

```
sep/htdemucs/<song>/
  vocals.wav
  drums.wav
  bass.wav
  other.wav
```
