指标说明：

- `sub%` / `mid%` / `hi%`：20–120Hz / 300–1000Hz / 4000–11000Hz 的能量占比
- `K/s` / `S/s` / `h/s`：kick / snare / hihat 每秒触发次数（分频段 onset 检测）
- `和声同质度`：逐小节 chroma 向量的平均最佳余弦相似度，越接近 1 说明全曲和声越单一

### 四个共性

**1. 低频占四到五成**

六首全部在 42–53% 区间。普通流行歌的低频占比通常在 20–30%。

**2. 高频几乎没有**

2–4%，而正常混音的高频占比在 8–15%。这是“发闷”的直接原因。

**3. 和声同质度 0.985–0.995**

六首全部如此，等于**每一首从头到尾没有和声变化**。

雨爱的验证：94 个小节里 96% 的小节与其他小节相似度 > 0.95，第 10 小节与第 22–50 小节（连续 29 小节）几乎完全相同。

朋友的酒更极端：127 个小节 100% 相似度 > 0.95。

**4. 动态范围两极分化**

```
雨爱       174 dB
云原神     169 dB
AIZO       168 dB
宇宙冷漠   137 dB
星と僕らと  82 dB
朋友的酒    80 dB   ← 最平
```

### 三个差异

**BPM 分三档**：99.4 / 129.2 / 161.5

**鼓的密度差 5 倍**：宇宙冷漠 0.32 K/s 到朋友的酒 1.69 K/s

**AIZO 最极端**：军鼓 0.03/s、镲片 0.01/s，几乎没有中高频打击，纯低频轰炸。

## 二、鼓点规律性（重要修正）

> **早期结论「鼓点没有规律」是错误的，此处修正。**

最初的判断依据是「16 分音符网格上的分布太平坦」。但这个推理不成立：

```
分布平坦 = 每个格子都有鼓点
         ≠ 没有规律
```

高密度鼓（每拍都打）会让 16 个格子都有东西，分布自然平，但这恰恰是极规整的重复。

用自相关重新测量后，结论相反：

| 曲目 | 1 拍 | 2 拍 | 4 拍 | 8 拍 | 16 拍 |
|---|---|---|---|---|---|
| 雨爱 | 0.84 | 0.83 | 0.76 | 0.63 | 0.33 |
| 朋友的酒 | 0.81 | 0.68 | 0.41 | 0.11 | 0.00 |
| 宇宙冷漠 | 0.69 | 0.45 | 0.12 | 0.00 | 0.00 |

拍级自相关 0.68–0.84，**周期性相当强**。小节级能量周期同样明显：

```
雨爱        1 小节 0.51
朋友的酒    1 小节 0.70   2 小节 0.53   3 小节 0.43
宇宙冷漠    1 小节 0.85   2 小节 0.69   3 小节 0.52
```

### 「拆迁感」的真实成因

不是随机撒鼓，而是三点叠加：

**一、密度过高、没有留白**

宇宙冷漠 1 小节自相关 0.85，意味着每一拍几乎一模一样。全程满负荷，没有呼吸。

**二、低频压倒**

sub 占 42–53%，持续低频冲击。

**三、没有重音对比**

正常鼓有「重拍-轻拍」的层次，自相关会从 1 拍到 2 拍明显衰减。这三首从 1 拍到 2 拍几乎不衰减——**第一拍和第三拍一样重**，听觉找不到落脚点。

结论：**规律性极强，但全部用在「平均用力」上**。听起来乱，是因为听者找不到重音和层次，不是因为没有结构。

## 三、音源分离

用 demucs `htdemucs` 四轨分离（vocals / drums / bass / other）。

雨爱各轨响度：

| 轨 | 平均响度 |
|---|---|
| drums | -15.5 dB |
| vocals | -16.8 dB |
| bass | -21.0 dB |
| other | **-27.9 dB** |

`other` 比其他轨低 12 dB 以上，说明编配极其简单——主体只有鼓和人声，没有和声垫、没有弦乐铺底。

### 已知局限

demucs 会把「人声当打击乐用」的怪叫（“哈——”“崩——”这类短促爆破音）分到 drums 轨。这类声音与军鼓在频谱上高度重叠（瞬态陡峭 + 宽频噪声），任何分离模型都难以区分。

## 四、复现方法

```bash
# 1. 从 B 站缓存提取音频
python tools/bili_cache_extract.py <cid> <输出目录>

# 2. 四轨分离
python -m demucs -n htdemucs --out sep input.mp3

# 3. 基础指标
python tools/analyze.py input.mp3
```

鼓点时间点导出在 `sifeng/beats/*.csv`，格式 `time_sec,type`（K/S/h）。
